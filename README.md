# ForgeTech

**ForgeTech - Computer Building Simulator**

Wersja: **0.0.1.0 BETA**

ForgeTech to przeglądarkowy symulator budowania komputerów z trybem Sandbox oraz Kariera. Gra działa bez instalowania dodatkowych bibliotek i może być uruchomiona bezpośrednio w przeglądarce.

## Funkcje

- 🧪 tryb Sandbox
- 🚀 tryb Kariera z własną firmą
- 🖥️ składanie komputerów z różnych podzespołów
- 🏭 produkcja i kolejka komputerów
- 🏢 rozwój firmy i zakup biur
- 👷 pracownicy z poziomami 1–50
- 💰 miesięczne koszty pracowników
- 📦 magazyn firmy z podglądem posiadanych rzeczy
- 📣 system reklam
- 🧠 punkty technologiczne i odblokowywanie części w Karierze
- 💾 zapis postępów Kariera w pamięci przeglądarki
- ⚙️ ustawienia i obsługa trybu pełnoekranowego
- 📱 interfejs przystosowany również do mniejszych ekranów

## Uruchomienie lokalne

Nie jest wymagany Node.js, Python ani żaden serwer.

1. Pobierz repozytorium.
2. Otwórz `index.html` w przeglądarce.
3. Gra powinna uruchomić się od razu.

## GitHub Pages

Repozytorium jest przygotowane tak, aby `index.html` był stroną startową GitHub Pages.

W ustawieniach repozytorium wybierz:

**Settings → Pages → Deploy from a branch → main → /(root)**

Po chwili GitHub Pages udostępni grę pod adresem repozytorium Pages.
